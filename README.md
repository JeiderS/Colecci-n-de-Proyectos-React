⚛️ Colección de Proyectos React

🚀 Este repositorio contiene múltiples aplicaciones desarrolladas con React, organizadas en una estructura modular dentro de una carpeta principal.

📌 Proyectos Incluidos
🔢 Contador – Aplicación simple para incrementar y decrementar un número.
🧮 Calculadora – Calculadora funcional con operaciones matemáticas básicas.
✅ Aplicación de Tareas – App para agregar, completar y eliminar tareas.

📦 Tecnologías Utilizadas

✅ React
✅ JavaScript (ES6+)
✅ CSS (para estilizar las apps)
✅ Vite (para desarrollo rápido)
